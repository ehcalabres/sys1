Regeneration commands and test instructions are in the repository README.
`d1_parsing_reference.json` comes directly from the first revision's `parsing.py`.

`d1_cats.png` is a lossless RGB conversion of COCO validation image
[000000039769.jpg](http://images.cocodataset.org/val2017/000000039769.jpg), the
cats-and-remotes example used in LiquidAI's model cards. Using the same decoded
PNG pixels avoids JPEG-decoder differences in model parity checks. The other
image, video, and audio inputs are generated by the reference scripts and native
test helpers.
